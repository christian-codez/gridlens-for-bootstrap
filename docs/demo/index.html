GridLens demo page

A Bootstrap 5 page for testing the grid overlay, tooltip viewer, and component opener.

How to test each feature

  1. 1Grid — click the GridLens icon, then Show Grid. The 12-column overlay appears and the breakpoint readout docks top-right. Resize the window and watch it change.
  2. 2Tooltips — switch to the Tooltips tab and click Show All Tooltips. All five below appear at once.
  3. 3Components — the Components tab lists everything on this page: modals, an offcanvas, a toast, a dropdown, tabs, accordion sections, a carousel and a popover. Several have no trigger anywhere on the page.
